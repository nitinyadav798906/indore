# UTK Project Starter

## Requirements
- Python 3.10 or newer
- Git
- A GitHub account

## Installation

Create a virtual environment:

python -m venv .venv

Activate it on Windows PowerShell:

.venv\Scripts\Activate.ps1

Install dependencies:

pip install -r requirements.txt

## Run

Check the public service homepage:

python utk.py --check-service

Display available commands:

python utk.py --help

## Upload to GitHub

Initialize Git:

git init

Stage project files:

git add .

Create the first commit:

git commit -m "Add UTK project starter"

Set the default branch:

git branch -M main

Connect your GitHub repository:

git remote add origin https://github.com/YOUR-USERNAME/utk-project-starter.git

Push the files:

git push -u origin main

Replace YOUR-USERNAME with your GitHub username.

## Security

Never commit passwords, session cookies, or access tokens.

Use official APIs and authorized account access.

This starter does not bypass subscriptions or extract
protected video URLs.
